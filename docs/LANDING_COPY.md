## English (short)

### Headline
**Copying the file does not copy the right to use it.**

### Subhead
TDCP is a data-centric protocol: encrypted packages stay storage-neutral; authorization lives in an Authorization Authority your Gatekeeper must call.

### Bullets
- **Package ≠ authorization** — ciphertext can move; grants and revoke stay on the control plane
- **Gatekeeper-only unlock** — READ / RENDER / EXTRACT with one-time grants and replay protection
- **Hosted Authority (Starter)** — durable revoke/replay for teams that do not want to run the control plane themselves
- **Self-host free** — open protocol reference and TypeScript integrator path

### CTA
Evaluate the protocol on GitHub · Talk to us about Hosted Authority Starter

### Fine print
Browser demo Oracle is not a production trust boundary. File-backed signing keys are development-grade. Production requires remote Authority with proper key custody and review — we do not claim certification here.
